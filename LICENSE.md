# Licensing

**There is no single licence covering this repository.** Each contribution carries its own terms,
and often different terms for different files inside it. Check the `LICENSE.md` in the contribution
you are reusing, every time.

This file explains how licensing works here. It does not itself grant you anything.

---

## The structure

| Layer | Typical terms | Where it is recorded |
|---|---|---|
| Repository scaffolding — templates, schemas, scripts, docs | `CC-BY-4.0` for prose, `MIT` for code | This file |
| A contribution's documentation and instructional material | Chosen by its authors, usually `CC-BY-4.0` | That contribution's `LICENSE.md` |
| A contribution's code | Chosen by its authors, usually `MIT` | That contribution's `LICENSE.md` |
| Sample data inside a contribution | Whatever its original source carries, file by file | That contribution's `LICENSE.md` |

## What is explicitly **not** licensed here

**Material owned by AWS, by a contributing institution, or by any other third party is not
relicensed by this repository, and no permission over it is granted by anything in it.**

Where such material is relevant, this repository links to the original rather than redistributing
it. If you find third-party material that appears to have been redistributed without authorization,
[report it](../../issues/new?template=report-problem.yml) — maintainers treat these as urgent.

This includes:

- AWS training content, branding, documentation, and course materials.
- Publisher textbooks, figures, and question banks.
- Institution-owned course materials contributed without the institution's authorization.
- Anything a contributor could not confirm they had the right to share.

## Attribution

When you reuse a contribution, credit it. Each ships a `CITATION.cff` with the citation its authors
ask for; at minimum name the contribution, its ID, its authors, and the version you used.

Under `CC-BY-4.0` you must also link to the licence and say whether you made changes. Adapting a
rubric or a lab for your own course is exactly what these materials are for — just say that you
adapted it.

## Questions

Unsure whether a reuse is allowed? Ask before you publish. Open a
[problem report](../../issues/new?template=report-problem.yml) marked as licensing, or contact the
maintainers through the [organization profile](https://github.com/DTC-Consortium).

Further detail for contributors and reviewers: [`docs/licensing.md`](docs/licensing.md).

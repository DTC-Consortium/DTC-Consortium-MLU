# Prof. James Chen — CS Code Critique Generator

PROMPT TEMPLATE:
You are a code-review tutor. Here is a piece of code that I need help with. Please follow the instructions below:

1. Identify the inefficiency, bug, or anti-pattern in the code.
2. Do NOT write or output corrected code under any circumstances. State this refusal explicitly.
3. Ask exactly 1-2 Socratic questions that guide me toward the fix.
4. Cite ONE specific concept, data structure, or pattern from the source material, naming it explicitly.

Here is my code:

[STUDENT CODE HERE]

INSTRUCTOR NOTE:
Introduce this template to students by explaining that it is designed to help them get the most out of their code review sessions by prompting them to think critically about their code. Emphasize the importance of identifying problems on their own and the value of Socratic questioning in fostering independent problem-solving skills. Explain that by using this template, students will be better equipped to understand and fix their code, leading to improved programming skills and efficiency.
